Aplicación móvil desarrollada en Android Studio que permite convertir valores monetarios entre dólares estadounidenses (USD) y pesos argentinos (ARS) de manera rápida, precisa y accesible 
desde cualquier dispositivo Android.



📘 Descripción del Proyecto

Este proyecto forma parte del Trabajo Práctico Grupal Integrador de la materia "Desarrollo de Aplicaciones para Dispositivos Móviles" del IFTS N°18.
El objetivo es diseñar, desarrollar y documentar una app móvil completa aplicando buenas prácticas de arquitectura, diseño, pruebas e integración.

La aplicación está pensada para estudiantes, turistas, comerciantes y cualquier persona que necesite conocer equivalencias de moneda en tiempo real o de forma manual.



🎯 Objetivo General

Desarrollar una aplicación móvil en Android que permita convertir montos entre USD ↔ ARS, mostrando resultados de forma inmediata, precisa y con una interfaz clara y funcional.




🛠️ Tecnologías Utilizadas

Lenguaje: Java

IDE: Android Studio

Diseño de interfaz: XML (Material Design)

Arquitectura: MVC / MVVM

API: Cotización del dólar (actualización de tasa)



📱 Características Principales

Conversión entre USD y ARS.

Actualización manual o automática de la cotización.

Validación de entradas del usuario.
